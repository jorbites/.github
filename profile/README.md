## 👋 Welcome to Jorbites

**Jorbites** is a vibrant, open food platform designed for home cooks, passionate foodies, and culinary creators. Whether you are looking for dinner inspiration, documenting family traditions, or participating in seasonal cooking contests, Jorbites gives you the tools and community to elevate your culinary journey.

### ✨ What You Can Do on Jorbites

- 🍳 **Discover & Share Recipes:** Step-by-step guides, ingredient lists, prep techniques, and mouth-watering photography.
- 🏆 **Events & Challenges:** Compete in weekly ingredient challenges, regional culinary contests, and earn exclusive digital badges.
- 📖 **Stories & Articles:** Read and publish culinary essays, gastronomic travels, and foodie lifestyle articles.
- 🥑 **Community & Gamification:** Like, comment, save favorites, gain XP, level up, and climb the Top Jorbiters leaderboard.
- 📱 **PWA & Multilingual:** Available in English, Spanish, and Catalan with a responsive, installable mobile app experience.

## 🏛️ Ecosystem & Repositories

The Jorbites platform is built as an open, scalable microservices ecosystem:

| Repository | Description | Tech Stack |
| :--- | :--- | :--- |
| **[jorbites](https://github.com/jorbush/jorbites)** | Main web platform, API, interactive UI, and PWA | Next.js, React, TypeScript, Tailwind CSS, Prisma, MongoDB |
| **[content](https://github.com/jorbites/content)** | Centralized content repository for blogs, events, challenges, images & badges with Git CMS | Sveltia CMS, GitHub Actions, Sharp, Gemini AI |
| **[badge_forge](https://github.com/jorbush/badge_forge)** | High-performance calculation engine for user badges, streaks, and achievements | Rust |
| **[jorbites-notifier](https://github.com/jorbush/jorbites-notifier)** | Real-time push and email notification service with FIFO queue | Go |
| **[tagatoni](https://github.com/jorbush/tagatoni)** | Autonomous background agent for recipe auditing, tagging, and SEO enrichment | Rust |
| **[pantry_keeper](https://github.com/jorbush/pantry_keeper)** | Automated scheduled database backup and data integrity monitor | Python |
| **[paltin-dash](https://github.com/jorbush/paltin-dash)** | Fun 3D endless runner video game starring Paltín the avocado mascot | React, Three.js / Canvas |
| **[jorbites-scripts](https://github.com/jorbites/jorbites-scripts)** | CLI admin tool for database management, user badges, and maintenance | Go |
| **[jorbites-instagram-giveaway](https://github.com/jorbites/jorbites-instagram-giveaway)** | Verification and winner selection engine for Instagram giveaway campaigns | Python |
